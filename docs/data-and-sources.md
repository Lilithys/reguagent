# Data and sources

项目使用 `calibrated_v0_2/` 作为唯一运行基线，版本 0.2.1。场景日期为 2026-09-08，组合资料保留各自的原始快照日期。运行时答案、行动和证据写入案件数据库。

| 数据类别 | 内容与使用方式 |
|---|---|
| 监管资料 | 来源登记、整理后的要求及段落定位，区分转述与原文 |
| Northstar 机构资料 | 虚构银行的业务、组合、政策、控制、流程、系统及角色 |
| 经济参数 | 三种响应模板、人天与费用假设，用于条件性比较 |
| 演示材料 | 标记为 synthetic 的业务答复、不相关政策、设计与测试样本 |
| 同业参考 | bunq 公开报告的参考登记，不作为 Northstar 本行事实 |
| 开发评测数据 | `evaluation_ground_truth/`，不进入模型允许的运行时检索目录 |

SME 主线围绕 10000 个客户、€2300m 的场景组合。模拟能源数据答复的 65% 用于计算完整度与补采数量，不被视作风险概率、损失或自动化率。

模型查询由运行时允许清单限制，控制映射视图移除预填映射答案，同时保留治理正文。引用 ID 和原文定位随工具结果返回；未提供的信息保持未知。

来源网址及引用位于 `regulatory_sources/change_register.json` 和 `requirements.json`。同业报告登记保留在 `reference_only/`，原始第三方 PDF 不随提交包分发；当地副本路径仅供原开发资料库定位。

字段与单位见 [数据字典](../calibrated_v0_2/DATA_DICTIONARY.md)。基础结构校验通过 `make validate` 运行。法规解释保留 provisional/silver 审核状态，法律文本、候选解释和人工决定分别记录。
